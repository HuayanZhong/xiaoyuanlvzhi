# Proposal

## Why

学生端上一版视觉升级沿着“移动优先 + 双色台账”落地：页面被固定在 30rem 手机列，底部导航在桌面上仍然存在，细线只做了分组，没有形成可辨认的风格。桌面用户看到的是一条居中的窄带，而不是一个 Web 应用；颜色上又保留了“植物 = 绿色”的状态戳，整体仍接近模板。

产品本质是“校园绿植领养站发给学生的一本养护档案”：植株有编号、领养要审核、积分有流水、兑换有截止。视觉应该像一份被认真归档的校园标本页，而不是手机 App 截图或环保营销页。现在需要一个能在没有图片、没有插画、没有 webfont 的条件下成立的整体风格，并且桌面和窄屏都成立。

## What Changes

- 页面壳改为**桌面优先**：≥48rem 使用纸色顶栏、横向导航、主题切换和最大 70rem 纸面；<48rem 才使用压缩顶栏 + 底部导航；首页和“我的”在宽屏使用双栏档案布局。
- 视觉方向改为**线装标本档案**：冷纸白、1px/2px 线条、宋体 display、系统黑体正文、等宽数据、点引线、方形记号和双线印章；不再使用植物绿和大面积墨色填充。
- 建立 palette → semantic 两层 token，并提供日间/暗夜两套 palette；组件只消费 semantic 层，原始色值只出现在 `tokens.css`。
- 新增**暗夜模式**：顶栏和认证页提供主题切换，首帧按 `localStorage` 或系统偏好设置 `data-theme`，避免闪白；选择持久化。
- 重做招牌结构：`TagRow` 使用方形套印记号 + 11px 标签 + 点引线 + 值 + 编号/日期 + 双线印章；新增 `FolioSection` 档案区块头；`Stamp` 改双线橡皮章。
- 统一组件状态语气：按钮改为线框五态，输入框直角 + 1px 交互边界，错误/警告/成功使用线条和措辞，空态使用虚线空档框。
- 修复 token 漏洞并扩展校验：未定义 `var(--*)`、组件 raw color、日间/暗夜对比度都由 Vitest 兜住。
- 明确不做：植物=绿色、奶油 + 衬线 + 陶土、近黑底 + 荧光绿、报纸式密排多栏、卡片堆叠、大圆角 + 柔阴影、渐变/玻璃/发光、环保图标、游戏化、中文 webfont、图标库、admin 改动、API/认证/路由/数据流改动。
- 保留被测试与 spec 锁定的类名和文案（如 `.ui-bottom-nav__link--active`、“暂无在养绿植”“未填写”），只改容器、排版、页面壳和状态语法。

## Capabilities

### New Capabilities

- `web-visual-system`: 学生端的线装档案视觉语言、日间/暗夜色板、排版三角色、桌面页面壳、线条表面、印章与字段行、组件状态和主题切换。

### Modified Capabilities

- `web-shell`: 页面壳从“移动优先 + 始终底部导航”改为“桌面顶栏 + 窄屏底部导航”；新增桌面双栏、主题切换入口，并保持 320px 无横向滚动与可访问性。

## Impact

- 受影响应用：`apps/web`。
- 受影响文件：`apps/web/app/assets/css/tokens.css`、`base.css`、`forms.css`、`layouts/*`、`components/*`、`pages/*`、`nuxt.config.ts`，以及新增的 `TagRow / Stamp / Ledger / FolioSection / ThemeToggle`、`useTheme` 和 token 校验测试。
- 不修改 Spring API、认证流程、路由、数据流、共享包或依赖；不改变端口与包边界。
- 不是 **BREAKING**：现有 URL、表单字段、测试锁定文案与无障碍语义保持不变；主题切换是新增能力。
