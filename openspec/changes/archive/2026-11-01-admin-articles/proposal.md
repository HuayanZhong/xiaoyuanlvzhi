# Proposal

## Why

管理端导航中的“资讯管理”仍是占位页。后端 `content` 模块已有基础接口，但管理端列表缺少摘要与详情分层，列表响应会携带完整正文，状态过滤和字段边界也缺少测试覆盖。补齐资讯管理，可以完成管理端最后一个业务 CRUD 页面，并为后续学生端资讯展示提供可靠的内容管理入口。

## What Changes

- 新增 `/articles` 资讯管理页面：列表、状态/关键词/分类筛选、分页、详情与编辑抽屉。
- 支持草稿、发布、编辑、重新发布和撤回；保存内容不改变发布状态，撤回需要二次确认。
- 编辑字段包括标题、分类、摘要、封面和正文；封面复用公开图片上传，正文使用纯文本并保留换行。
- 调整 Spring 管理端接口：列表改为不含正文的摘要视图，新增详情接口；现有新增、编辑、发布、撤回接口保留并明确状态语义。
- 补齐资讯接口的状态过滤校验、去除首尾空白后的长度校验和测试覆盖。
- 更新 `admin-shell` 的占位页要求、`README.md` 和管理端产品文档。
- 不涉及认证流程、共享包、环境变量或工具链变更。

## Capabilities

### New Capabilities

- `admin-articles`: 管理端资讯的列表、筛选、分页、详情、编辑、发布、重新发布、撤回，以及标题、分类、摘要、封面和正文的字段规则。

### Modified Capabilities

- `admin-shell`: `/articles` 从占位页变为真实资讯管理页面，剩余占位模块仅数据统计。

## Impact

- 应用：`apps/admin`。
- Spring：修改 `content` 模块的管理端接口和 DTO；公开资讯接口保持现有行为，仅管理端列表响应改为摘要视图并新增详情接口。
- API：`GET /api/v1/admin/articles` 返回摘要列表；新增 `GET /api/v1/admin/articles/{id}`；管理端写接口响应补充作者姓名。不涉及认证、角色边界或数据库迁移。
- 文档：`README.md`、`docs/product/admin.md`。
- 测试：admin 单元测试；Spring 管理端控制器契约、服务和持久化适配器测试。
- 兼容性：管理端列表响应结构变化，但当前 admin 页面仍是占位页，没有其他管理端消费者；公开接口不变。端口、路由、包边界和工具链无破坏性变更。
