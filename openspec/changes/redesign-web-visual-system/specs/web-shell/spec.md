# Spec Delta

## MODIFIED Requirements

### Requirement: 首页区块布局

首页 SHALL 依次展示六个区块：我的绿植、待处理事项、当前积分、环保任务、养护提醒、消息。桌面视口 SHALL 使用两列布局，窄屏 SHALL 使用单列布局。档案编号、建档日期和档案状态条 SHALL NOT 再出现。

#### Scenario: 桌面查看首页

- **WHEN** 已登录学生在 768px 及以上视口访问 `/`
- **THEN** 页面按顺序显示六个区块，并以两列排列

#### Scenario: 窄屏查看首页

- **WHEN** 已登录学生在窄屏访问 `/`
- **THEN** 六个区块按顺序单列显示，不产生横向滚动

#### Scenario: 不再显示档案条

- **WHEN** 已登录学生访问 `/`
- **THEN** 页面不出现「档案编号」「建档日期」或「档案状态」字样或对应区块
