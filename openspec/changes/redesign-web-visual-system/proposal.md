# Proposal

## Why

学生端现有的「线装标本档案」视觉与「绿植领养」产品的情感预期冲突：冷纸、墨线、
档案术语与满屏英文微标签，让页面显得混乱、没有清晰方向。7 路并行样式审计发现
115 处与旧视觉文档的偏差、78 条混乱因素，根因是 token 治理失控（颜色四代命名、
35 处裸字号、断点碎裂）与招牌组件覆盖不齐（4 种区块头、5 种行结构、3 种列表节奏）。
用户已选定新方向「生长手帐」，需要整体替换视觉语言并重建 token 纪律。

## What Changes

- 学生端视觉语言由「线装标本档案」替换为「生长手帐」：奶油纸底、楷体标题、
  胶囊组件、叶绿主色、贴纸与和纸胶带成就装饰，正文与数据保持黑体清晰。
- 重建设计 token：颜色只保留 palette → semantic 两层；字号、间距、圆角、阴影、
  动效全部 token 化；删除旧命名别名、死 token 与私有断点。
- 统一组件语言：全站一个区块头、一种字段行、两种列表节奏、一种空态、一种错误
  通道；移除档案编号卷号、英文微标签、橡皮章与点引线。
- 移除首页的「档案编号 / 建档日期 / 档案状态」条，六区块内容与双栏布局不变。
- 日间/暗夜两套配色按新 palette 重做，保留主题切换、首帧防闪白与持久化。
- 重写 `docs/design/web-visual-system.md` 为《生长手帐视觉系统》。

**BREAKING**：无端口、路由、包边界或工具链变更。视觉契约整体更换，但 URL、
表单字段、认证流程、数据流与无障碍语义保持不变。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `web-visual-system`：视觉语言、颜色与排版角色、表面与形状、组件语气、token
  架构、空态与动效的需求整体替换为生长手帐体系。
- `web-shell`：首页区块布局移除档案编号、建档日期和档案状态条。

## Impact

- 受影响应用：仅 `apps/web`（Nuxt 学生端）。
- 代码：`app/assets/css/{tokens,base,forms}.css`、`app/layouts/default.vue`、
  `app/layouts/auth.vue`、18 个组件、19 个页面，以及
  `docs/design/web-visual-system.md`。
- 不涉及：Spring 接口、`admin` 应用、`@repo/*` 共享包、环境变量、构建与测试
  工具链；本变更不新增 API、认证或持久化需求。
- 既有测试中按视觉契约断言的类名与文案在同一变更内同步更新。
