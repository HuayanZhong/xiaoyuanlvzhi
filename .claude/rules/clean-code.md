# 干净的注释与配置

- 注释只解释代码无法直接表达的意图、约束和边界；不复述类型、实现步骤或显而易见的赋值。
- 公共 API 使用 JSDoc，按“职责 → 关键约束/易错点 → 最小示例”组织；示例应贴近真实调用。
- 配置保持单一来源：默认值写成具名常量或在声明处说明，不在多个层级重复同一配置。
- 共享包保持环境无关，只接收普通配置值；环境变量和框架全局对象只在应用适配层读取。
- 中文用于意图和约束说明；标识符、命令、协议字段和类型名保持原文。
- 删除装饰性注释、历史备注和与当前行为无关的配置，不引入第二套工具链。
- 修改公共 API 或配置时，同步更新测试和最近的使用示例。
