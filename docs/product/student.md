# 学生端产品规格

本文定义学生从注册到领养、参与环保行动、获得积分和兑换奖励的页面与操作。首版主导航为：首页、绿植、任务、积分、我的。页面必须把当前状态、下一步操作和审核原因说清楚；学生不需要知道管理员后台如何分工。

## 1. 注册与登录

### 注册字段

| 字段     | 必填 | 校验与说明                           |
| -------- | ---- | ------------------------------------ |
| 姓名     | 是   | 1–30 字                              |
| 学号     | 是   | 全系统唯一；首版不接学校统一身份认证 |
| 院系     | 是   | 1–60 字；首版使用文本输入            |
| 班级     | 是   | 1–40 字                              |
| 手机号   | 是   | 手机号格式；同一手机号只绑定一个账号 |
| 登录密码 | 是   | 6–20 位；注册和登录错误提示使用中文  |
| 确认密码 | 是   | 必须与登录密码一致                   |

提交成功后进入首页并保持登录状态。管理员可以禁用学生账号；禁用后登录时显示“账号暂不可用，请联系管理员”。首版不提供学生自选管理员身份，也不实现找回密码自助流程；忘记密码提示联系管理员。

### 登录

登录字段为学号和密码。空字段显示就地错误；错误账号或密码显示统一提示，不暴露账号是否存在。登录成功进入首页。退出登录后回到登录页。

## 2. 首页

### 页面区块

- **我的绿植：** 显示在养数量；点击进入“我的绿植”。
- **待处理事项：** 显示待审核打卡、被驳回需重新提交、待领取奖励等数量；点击进入对应记录。
- **当前积分：** 显示余额；点击进入积分明细。
- **环保任务：** 展示最多 3 个当前可报名任务；点击进入任务详情或任务列表。
- **养护提醒：** 展示已达到打卡时间的绿植；点击进入对应绿植详情。
- **消息入口：** 显示未读数；点击进入通知列表。

未登录状态展示登录/注册入口。数据为空时用说明和行动按钮引导，例如“还没有领养绿植，去看看可领养品种”。

## 3. 绿植与领养

### 3.1 绿植列表

每张卡片显示品种图片、品种名称、养护难度/说明摘要、可领养数量和校区位置。提供品种关键词和位置筛选。只展示启用品种及至少有一株“可领养”单株的品种；无结果时显示清空筛选入口。

### 3.2 品种详情与申请

详情显示品种图片、光照说明、浇水说明、养护间隔、可领养数量和领取地点。点“申请领养”打开确认页：

| 字段/信息 | 规则                                     |
| --------- | ---------------------------------------- |
| 申请品种  | 必填，默认当前品种；提交后不可自行改品种 |
| 申请备注  | 可选，最多 200 字                        |
| 领取说明  | 展示管理员确认后通知的线下领取方式       |

提交前确认申请信息。提交成功后进入申请详情，显示申请编号、提交时间和“待审核”。学生不能选择具体单株；管理员通过后分配实际植株。名额不足时不允许提交，并提示该品种当前没有可领养绿植。

同一学生对同一品种已有待审核申请时，详情页按钮改为“查看申请”，不重复创建申请；可申请不同品种。

### 3.3 我的申请与状态

申请列表按最近更新时间倒序，展示品种、提交时间、状态和最近处理意见。

| 状态       | 学生看到的说明                | 可执行操作                         |
| ---------- | ----------------------------- | ---------------------------------- |
| 待审核     | 管理员正在审核                | 撤回申请                           |
| 已驳回     | 显示管理员原因                | 修改备注后重新提交                 |
| 待领取     | 显示分配的单株和领取地点/期限 | 查看领取说明；线下交接由管理员确认 |
| 取消审核中 | 管理员正在处理取消申请        | 查看申请进度                       |
| 养护中     | 申请已转为有效领养            | 查看“我的绿植”                     |
| 归还审核中 | 管理员正在确认归还            | 查看申请时间和说明；不能重复申请   |
| 已结束     | 显示结束时间和植株处理结果    | 查看历史记录                       |
| 已取消     | 显示取消或超时原因            | 重新申请                           |

学生撤回只能发生在“待审核”；待领取阶段如不再需要，可申请取消并由管理员确认，避免已分配植株被静默释放。

## 4. 我的绿植与养护打卡

### 4.1 我的绿植列表

每项显示植物展示名/品种、单株编号、位置、领养开始日期、状态、下一次可打卡日期。点击进入详情。

### 4.2 绿植详情

展示管理员维护的养护说明、位置、领养状态时间线、历史打卡及审核原因。达到养护间隔后显示“提交养护打卡”；未到时间显示下次可提交日期。状态为归还审核中或已结束时不允许提交打卡。

### 4.3 养护打卡表单

| 字段     | 规则                   |
| -------- | ---------------------- |
| 养护说明 | 可选，最多 300 字      |
| 现场照片 | 可选，最多 3 张        |
| 凭证要求 | 说明或照片至少填写一项 |

提交后生成一条“待审核”记录，记录不能直接删除。审核通过后显示获得积分；驳回后显示管理员原因和“修改后重提”。重提保留之前的提交和审核历史，同一条打卡最终只获得一次积分。

### 4.4 申请归还

在绿植详情点“申请归还”，填写原因 5–200 字并确认。提交后状态变为“归还审核中”，暂时关闭该株新的打卡入口。管理员确认实物并处理后，学生收到结束结果；若被驳回，显示原因并恢复在养状态。

## 5. 环保任务

### 5.1 任务列表与详情

列表仅展示已发布任务，支持按“可报名、已参加、已结束”筛选。卡片显示标题、开放时间、剩余名额、单人奖励积分和当前状态。

详情显示完整任务说明、完成标准、凭证要求、时间范围、名额和奖励积分。未开始、已结束、已满额或已报名时，主按钮分别显示“尚未开始”“任务已结束”“名额已满”或“查看进度”，不能重复创建参与记录。

### 5.2 报名与提交凭证

学生在开放时间内点“参加任务”后生成一条参与记录。完成后提交任务要求的文字说明和/或照片，字段要求由任务配置决定；首版文字最多 500 字，照片最多 3 张。

提交后状态为“待审核”。审核通过后展示通过结果和积分入账明细；驳回后展示原因和重新提交入口。允许在任务截止时间前修改重提，历史凭证不覆盖。任务结束后不能新增报名或提交；截止前已提交的记录仍可等待管理员审核。

## 6. 积分、奖励和兑换订单

### 6.1 积分明细

顶部显示当前余额；明细按时间倒序，显示时间、来源业务、来源记录、增加/扣减积分和变动后余额。积分来源至少区分养护打卡、环保任务、兑换、冲正和管理员调整。学生不能自行修改积分。

### 6.2 奖励商城

商品卡片显示名称、图片、兑换所需积分、剩余库存和领取地点。积分不足、库存不足或商品下架时禁用兑换按钮并显示原因。

点“兑换”后显示确认弹窗，列出将扣除积分、领取地点和领取截止时间。确认后创建“待领取”订单，并立即扣减积分、占用库存。首版推荐领取期限默认 7 个自然日，具体天数可由管理员在商品中配置。

### 6.3 订单列表与取消

订单展示订单号、商品、兑换积分、下单时间、领取地点、截止时间和状态。

- 待领取：学生可取消；二次确认后订单变为已取消，积分退回、库存释放。
- 已领取：显示领取完成时间，不提供取消。
- 已取消/已超时：显示结果和积分退回记录。
- 到期未领取：系统自动标记已超时，并退回积分、释放库存。

兑换确认时如果余额或库存已经变化，显示“积分或库存不足，请刷新后重试”，不能生成订单。

## 7. 我的、通知与问题反馈

### 个人资料

展示姓名、学号、院系、班级、手机号；允许修改手机号和班级，姓名和学号需联系管理员更正。退出登录后回到登录页。

### 通知列表

按时间倒序展示标题、摘要、业务类型、时间和已读状态。通知范围包括领养审核、交接、归还、打卡审核、任务审核、积分变化、兑换履约/取消/超时及活动公告。点击通知打开对应业务详情；查看后标记已读；提供“全部标记已读”。

### 问题反馈

首版提供反馈表单：问题类型（绿植问题/账号问题/奖励问题/其他）、关联记录（可选）、描述（必填，5–500 字）、照片（可选，最多 3 张）。提交后显示反馈编号和“待处理”；学生能查看管理员回复。该模块用于闭合首版无法自助处理的异常，不等同于完整申诉系统。

## 8. 学生端验收流程

1. 新学生注册后能浏览绿植、提交申请并看到待审核状态。
2. 管理员驳回申请后，学生看到原因并可修改重提；管理员通过后，学生看到分配的单株和领取信息。
3. 管理员确认交接后，该绿植出现在“我的绿植”；达到养护间隔时可以提交打卡。
4. 打卡或任务凭证被驳回后，学生能查看原因并重提；通过后积分明细出现对应记录。
5. 学生积分不足、库存不足时不能兑换；兑换成功后看到待领取订单和截止时间。
6. 学生取消待领取订单或订单超时后，能看到积分退回及订单状态。
7. 学生提交归还申请后不能重复提交；管理员处理后收到归还完成或驳回通知。
