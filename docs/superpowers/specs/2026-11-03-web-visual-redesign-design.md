# 学生端视觉重设计：生长手帐

- 状态：已被 `docs/design/web-visual-system.md` 的「一株」方案取代
- 日期：2026-11-03
- 范围：`apps/web`（Nuxt 学生端）全站样式、组件语气与视觉系统文档

## 1. 背景与判定

用户判定现有「线装标本档案」方向与「绿植领养」产品的情感预期冲突：冷纸、墨线、
档案术语与满屏英文微标签，让页面显得混乱、没有清晰方向。

7 路并行审计（tokens / 壳层 / 基础组件 / 招牌组件 / 三组页面）共发现与旧文档的
偏差 115 处、混乱因素 78 条，根因集中在两层：

- **Token 治理**：颜色四代命名并存（palette / semantic / status / 旧别名），字号
  三代命名并存，20 多个文件共 35 处裸写字号（含 9px、10px、22px、28px 等字阶外值），
  断点碎裂（48rem 两种写法 + 63.99rem / 30rem / 22.5rem 私有档），死 token 堆积。
- **招牌组件覆盖不齐**：同一系统里 4 种区块头、5 种行结构、3 种列表线节奏、2 种空态、
  3 种按钮来源，Ledger 组件零引用。

结论：**更换视觉方向，重建 token 与组件语言**，不修补旧方向。

## 2. 设计主张

把学生端做成一本**被认真装饰的成长手帐**：每株植物是手帐里的主角，养护打卡是贴在
日历上的叶子贴纸，积分是收藏进册子的成果。视觉识别来自**纸质温度 + 楷体标题 +
位置讲究的手帐装饰**；正文与数据永远是清晰的黑体，信息永远在装饰前面。

选择理由：手帐隐喻直接绑定产品最强的循环——「领养 → 打卡 → 积分」的日常记录，
这是本产品独有的识别来源，不依赖任何通用模板。备选的「清新自然系」底色与大量
绿色容易滑向环保宣传页，「现代简洁系」清晰但缺少陪伴感。

### 装饰纪律（浓郁档）

| 装饰       | 允许出现的位置                                     | 规格                                    |
| ---------- | -------------------------------------------------- | --------------------------------------- |
| 和纸胶带   | 卡片顶部一角（普通卡左上 -3°，双卡第二张右上 +2°） | 52×13px、透明度 0.8、黄/绿/珊瑚三色轮换 |
| 贴纸徽章   | 仅成就类信息（连续打卡 N 天、里程碑）              | 胶囊 + `0 2px 0` 落影                   |
| 纸面点纹   | 仅页面底层 paper                                   | 22px 点阵，暗夜减弱                     |
| 手绘下划线 | 仅页面级大标题，每屏一个                           | 64×6px 胶带条，微倾                     |
| 虚线框     | 仅「可参与/可书写」容器（打卡日历、表单组、空态）  | 1.5px dashed                            |
| 楷体       | 仅标题（页面/区块/字标），一律 400，禁伪粗         | 正文、按钮、数据永远是黑体              |

## 3. Token 体系

`app/assets/css/tokens.css` 是唯一来源，只保留 **palette → semantic** 两层，
不再有别名层与 status 层。

### 色彩

| Token         | 日间      | 暗夜（夜灯下手帐） | 职责                       |
| ------------- | --------- | ------------------ | -------------------------- |
| `paper`       | `#FBF7EE` | `#26241E`          | 页面底                     |
| `surface`     | `#FFFFFF` | `#2E2B24`          | 卡片、浮层                 |
| `ink`         | `#3B3830` | `#EAE4D4`          | 正文、标题                 |
| `subtle`      | `#8A8578` | `#A39D8D`          | 次级文字、hint             |
| `leaf`        | `#5C8A3C` | `#9CC06F`          | 主色：主按钮、链接、当前态 |
| `leaf-wash`   | `#EDF3E0` | `#333A28`          | 选中底、chip 底            |
| `soil`        | `#8A6B52` | `#B39A7E`          | 次级强调、编号             |
| `sticker`     | `#F2C14E` | `#E3B84E`          | 胶带、徽章、连续打卡       |
| `blush`       | `#C4553C` | `#E08A72`          | 警示、失败、破坏性         |
| `line`        | `#E5DCC8` | `#3E3A30`          | 装饰分隔                   |
| `line-strong` | `#C9BC9C` | `#5C5647`          | 交互边界（≥3:1）           |

对比度规则：正文与标题 ≥4.5:1；`leaf` 作为文字色仅限 ≥14px 粗体或带下划线的链接；
可点击边界一律使用 `line-strong`。

### 字体

- **楷体栈**（仅标题）：`"Kaiti SC", "STKaiti", "KaiTi", "楷体", serif`，400，
  `font-synthesis-weight: none`，不加载 webfont。
- **黑体栈**（正文与 UI）：系统字体栈，400/600/700。
- **数据**：黑体 700 + `tabular-nums`（仅数据角色使用）。

| 角色    | 规格                                              |
| ------- | ------------------------------------------------- |
| Display | 楷体 400，`clamp(1.75rem, 3vw, 2.25rem)` / 1.25   |
| 区块题  | 楷体 400，1.25rem / 1.3                           |
| 正文    | 黑体 400，0.9375rem（15px）/ 1.7                  |
| 小字    | 黑体 400，0.8125rem（13px）/ 1.6                  |
| Label   | 黑体 600，0.75rem（12px）                         |
| 读数    | 黑体 700，`clamp(1.5rem, 2.5vw, 2rem)`，单位 12px |

### 形状、阴影与纹理

- 圆角：卡片 16px、输入与小卡 12px、chip 与按钮胶囊、贴纸格 10px。
- 边框：表面卡 1px solid `line`；手帐容器 1.5px dashed（语义：可参与/可书写）。
- 阴影：仅两级——纸片感 `0 2px 0`（卡片、贴纸）与浮层
  `0 8px 24px`（对话框、下拉、提示）。
- 纹理：点阵仅作用于页面 paper 层；卡片表面永远纯色。

### 动效

只解释状态：按下 `scale(0.98)` 120ms；卡片 hover 抬 1px 160ms；贴纸「盖上」落定
（scale 1.2 → 1 + 微旋）240ms，仅用于打卡成功瞬间。全部走 CSS transition，
`prefers-reduced-motion` 下全部降级为无动画。

## 5. 结构清理（审计驱动）

1. **中文优先与编号纪律**：删除装饰性英文微标签；业务编号（PL/PT/SP-004/ADP-xxxx）
   只作为「编号 xxx」小字出现，绝不进入标题或正文语流。
2. **单一语言**：全站只有一个区块头、一种字段行、两种列表节奏、一种空态、一种错误
   通道；组件不各自发明断点。
3. **Token 治理**：tokens.css 只留两层；35 处裸字号全部收编；断点统一 48rem 一档
   （删除 63.99rem / 30rem / 22.5rem 私有档）；死 token 清零。
4. **内容噪点防护**：封面缺图使用纸纹 + 叶形 SVG 占位，不出现纯色大块；品种代号只
   出现在编号条。

## 6. 壳层与响应式

- **≥48rem**：顶栏 64px（奶油纸 + 虚线底边），楷体字标 + 文字导航；内容
  `max-width: 70rem`；页脚一行小字。
- **<48rem**：底栏 64px + 1px 顶线，5 个内联 SVG 叶形图标 + 中文；内容单栏；
  320 / 375 / 768 均无横向滚动，触控目标 ≥44px。
- **暗夜**：`<html data-theme>` 切换，绘制前由内联脚本读取持久化偏好；夜灯配色见
  色彩表。
- **无障碍**：所有交互元素可见 focus（2px leaf 外圈）；`prefers-reduced-motion`
  全降级。

## 7. 落地范围与顺序

涉及文件：`tokens.css`、`base.css`、`forms.css` 重写；`layouts/default.vue`、
`layouts/auth.vue`；18 个组件；19 个页面；`docs/design/web-visual-system.md` 全文重写。

1. **Token 层 + 壳层**：tokens/base/forms 重写，masthead、底部导航、认证布局。
2. **组件层**：Button/Input/chip/卡片/区块头/空态/时间线/图框/对话框/导航图标。
3. **页面层（三批）**：植物·领养·养护 → 任务·积分·兑换 → 通知·反馈·我的·认证·404。
4. **文档与清理**：重写视觉系统文档，删除死 token 与死组件分支，全站 grep 验收。

## 8. 验收标准

- `tokens.css` 之外无裸色值（grep `#hex`、`rgb(` 为零）与裸 `font-size`。
- 日/夜两套配色通过对比度检查（正文 ≥4.5:1，边界 ≥3:1）。
- 320 / 375 / 768 / 1440 宽度无横向滚动；触控目标 ≥44px。
- `pnpm --filter web test`、`check-types`、`lint` 全部通过。
- 明暗两套逐页截图复核，确认无第二套区块头/行结构/空态语言。

## 9. 明确不做

- 图标库、中文 webfont、动画库。
- 渐变、玻璃拟态、发光描边。
- 以 emoji 充当功能性图标（叶形贴纸用内联 SVG）。
- 大面积绿色块、营销页式视觉、满屏英文微标签。
