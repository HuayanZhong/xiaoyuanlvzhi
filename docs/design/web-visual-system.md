# 学生端视觉系统：一株

本文是 `apps/web` 的视觉定义源，`app/assets/css/tokens.css` 是可执行来源。
页面、共享组件和动效必须从这里取值，不在页面内另造颜色、字体和节奏。

## 1. 产品定位

学生端是桌面浏览器中的 C 端植物生活产品，不是管理后台。

品牌名：**一株**。副标题：**植物成长档案**。

视觉关键词：真实植物、编辑排版、安静留白、清晰操作、克制的物理反馈。

不使用学校名称、校徽、校园建筑、学号作为品牌视觉；学生资料只作为业务数据出现。

## 2. 画布与栅格

- 最小桌面宽度 `1180px`，不做移动端重排。
- 内容最大宽度 `1328px`，12 栏栅格。
- 1440px 视口外边距 `56px`，栏距 `24px`；1280px 外边距 `40px`，栏距 `20px`。
- 顶部导航 `72px`，首页主视觉 `560px`，大区块间距 `96px`，页头下留白 `56px`。
- 首页：5/7 栏主视觉，7/5 栏照料与行动，8/4 栏积分与消息。
- 绿植：7/5 栏重点品种，其余三列图鉴。
- 行动：5/7 栏重点行动，后续 12 栏列表。
- 积分：12 栏余额带，下方 8/4 栏流水与入口。
- 我的：4 栏 sticky 档案，8 栏连续内容。
- 登录：55/45 分栏；详情：5 栏媒体，7 栏内容。

## 3. 色彩

| Token     | 日间      | 暗夜      | 职责             |
| --------- | --------- | --------- | ---------------- |
| `paper`   | `#F2F4EE` | `#0B120E` | 页面背景         |
| `surface` | `#FCFDF9` | `#131E17` | 卡片、弹层、表单 |
| `ink`     | `#102019` | `#F4F6EF` | 标题与正文       |
| `subtle`  | `#5E7464` | `#BAC5BC` | 次级文字         |
| `leaf`    | `#173D2B` | `#D8E77C` | 主操作、当前态   |
| `citron`  | `#D8E77C` | `#E2EE91` | 少量成就强调     |

深色区域只使用松针绿；陶土色只用于提醒；嫩芽色不使用为大面积背景。

## 4. 字体

| 角色           | 字体                    | 规则                                                   |
| -------------- | ----------------------- | ------------------------------------------------------ |
| 品牌与展示标题 | `LXGW WenKai`           | 500，仅用于品牌、H1、H2 和短标题；首页 68px，页面 56px |
| 正文与控件     | `Noto Sans SC Variable` | 400/500，16px / 1.75                                   |
| 数字与英文索引 | `Fraunces Variable`     | 500，余额、标本编号、栏目英文索引                      |
| 标签           | `Noto Sans SC Variable` | 600，12px，字距 0.08em                                 |

不使用装饰性手写体和满屏文楷。长段正文仍使用无衬线字体；文楷只用于短标题，标题统一使用 `text-wrap: balance`。

## 5. 表面与组件

- 普通卡片、图片框和表单容器最大 `8px` 圆角。
- 输入框 `6px`，弹窗 `12px`，主 CTA 可使用胶囊形，状态标签 `4px`。
- 卡片使用 1px 边界和极短阴影，不使用大块浮动卡和卡片套卡片。
- 按钮高 `44px`；输入高 `48px`；图标按钮 `40px`。
- 标本签是唯一贯穿全站的标志性结构：真实名称、编号、位置、间隔和状态。
- 普通图标统一 Lucide 1.5px 线宽，尺寸 16/20/24。

## 6. 页面结构

### 首页

1. 左侧问候、当前植株、说明和主行动；右侧满高植物摄影。
2. 标本签跨图片左边界，与文字栏形成连接；影像裁切层独立，不跟随悬停溢出。
3. 今日照料包含养护队列、间隔与日期摘要、打卡前确认清单。
4. 环保行动展示最多三个可报名任务；我的绿植补充间隔、最近通过记录和最近养护历史。
5. 侧栏同时展示积分余额、最近三条有效积分变动和两条通知预览。
6. 页面底部提供绿植、行动、奖励、反馈四个常用入口，入口使用连续分隔带而不是重复卡片。

### 绿植与行动

- 绿植筛选器开放式排列，图鉴使用等权高密度卡片：5 个及以上五列，4 个四列，3 个三列，1–2 个两列。
- 绿植页增加品种数、可领养植株、新手品种、最短照料间隔四项概览。
- 筛选区提供关键词、位置、难度和库存条件；难度与库存条件写入 URL，并可本地即时过滤。
- 品种卡必须展示光照、浇水、照料间隔和照料积分，不再只显示名称、难度与数量。
- 图鉴末尾补充摆放、打卡和线下交接三条领养前须知。
- 行动以带真实状态的列表为主，不使用重复字段卡。
- 积分余额使用深色全宽带，流水保持连续阅读节奏。

### 账户与详情

- 账户页左侧粘性身份档案，右侧连续资料区。
- 详情页左侧固定媒体，右侧滚动内容与操作。
- 登录与注册为满高分栏照片和开放表单。
- 暗夜登录页的照片遮罩固定使用深林色，不跟随 `leaf` 变成大面积荧光黄绿；右栏使用近黑绿层次、细边界和低对比表面光，强调色只用于标题索引、焦点与主操作。

## 7. 图像

- 素材优先使用项目自有原创植物摄影；无封面时按品种名和 ID 稳定映射。
- 不使用学校实景、校徽、带人脸素材、假植物插画和纯色空框。
- 图片必须有尺寸、焦点位置和真实替代文本；装饰图使用空 alt。
- 使用 `<img loading="lazy">`，首屏图片显式标记优先加载。

## 8. 动效

- 按压 `120ms`，颜色 `160ms`，悬停 `180ms`，页面 `240ms`。
- 进入 `320ms`，图片揭示 `420ms`，退出 `140ms`。
- 常规缓动：`cubic-bezier(0.2, 0, 0, 1)`。
- 进入缓动：`cubic-bezier(0.16, 1, 0.3, 1)`。
- 内容默认可见，只在客户端成功加载后启用初始隐藏。
- `prefers-reduced-motion` 下关闭位移、缩放、View Transition、扫光与自定义光标。

## 9. Supermouse

- 仅精细指针设备启用，使用 Supermouse `Pointer` 描边箭头，不再使用内点、外环或粒子尾迹。
- 正常箭头 32px，悬停保持 32px，按下时缩至 30px，透明度为 0.96。
- 箭头使用官方路径：`36×36` 视口、内部 `rotate(-45 16 16)`、`#F2F5F8` 填充与 `#111920` 描边。
- 箭头随移动方向平滑旋转，静止 160ms 后回到 `0°` 的默认角度，`smoothness: 0.22`。
- 输入、文本域、选择框、可编辑区、上传拖拽区和文本选取区恢复原生光标。
- 用户可在「我的」关闭鼠标效果，偏好写入本地存储。
- 路由切换复用同一实例；插件卸载或 HMR 时销毁 rAF 和事件监听。

## 10. 明确不做

- 移动端布局、底部导航、卡片内再套卡片。
- 手帐、贴纸、胶带、纸张噪点、点击火花。
- 学校专属视觉、管理端侧栏、仪表盘式等宽六宫格。
- 直接请求 Spring、浏览器可读访问令牌、外部反向代理。
