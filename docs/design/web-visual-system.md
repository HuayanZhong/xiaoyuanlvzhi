# 学生端视觉系统：线装标本档案

本文记录 `apps/web` 的长期视觉规则。颜色、字号和间距的唯一来源是
`apps/web/app/assets/css/tokens.css`；本文解释角色和用法，不复制可执行实现。

## 主张

把学生端做成一份校园植物标本馆的**线装档案**：冷纸白、墨线、宋体标题、等宽编号，
再加一枚小的印泥红印章。页面像一张被认真归档的标本页，而不是手机 App 截图。

视觉识别来自**线条与排版**，不来自色块：masthead 的双细线、档案页眉的 2px 墨线、
带点引线的字段行、方形套印记号和旋转的双线状态戳。首个业务模块（绿植目录）开始
使用品种封面，但封面只进入固定画框，不替代名称、数量或状态文字。

本系统同时提供日间与暗夜两套纸色，语义 token 不变，只替换 palette。

## 页面壳

- **≥ 48rem（网页）**：页面息顶栏 72px，左侧印章字标 + 导航 + 主题切换；内容
  `max-width: 70rem`，首页与“我的”使用双栏档案布局；页脚一行等宽说明。
- **< 48rem（窄屏）**：同一顶栏压缩为 56px，只保留字标和主题切换；主导航改为
  底部固定栏；内容单栏。
- 不再使用 30rem 手机列。320 / 375 / 768 均无横向滚动，触控目标至少 44px。

## 颜色纪律

- **不使用植物绿**。在养、已通过、已领取用墨色双线印章 + 固定状态词表达，不用绿色。
- 印泥红只用于：卷号/区块索引、页眉小方点、待处理、失败、印章。不用于大面积底色、
  按钮填充或正文；同屏不得出现两块以上大面积印泥红。
- 主按钮是**墨色描边**，不是填充块；破坏性操作用深绛描边 + 深绛文字。
- 2px 墨线只用于 page header 底线和当前导航；其余分隔一律 1px。

## 字体

| 角色    | 规则                                                                                   |
| ------- | -------------------------------------------------------------------------------------- |
| Display | 宋体栈 400，`clamp(2.5rem, 5vw, 3.75rem)` / 1.08 / `+0.02em`；每屏一个                 |
| Section | 宋体栈 400，24px / 1.2，配 11px 等宽卷号与右侧英文标签                                 |
| Body    | 系统黑体 400，16px / 1.65；次级正文 14px / 1.6                                         |
| Data    | `--font-mono` + `tabular-nums`；读数 `clamp(2.25rem, 4vw, 3.5rem)`，编号与日期 12–14px |
| Label   | 11px / 500 / `+0.18em`，只用于 2–6 个汉字或短编号                                      |

宋体标题使用系统字体（macOS Songti SC、Windows SimSun、Linux Noto Serif CJK），
不加载 webfont；`font-synthesis-weight: none`。标题在任意断点都大于读数。

## 表面与形状

- 默认零阴影；所有分组靠 1px 线、双线、点引线和留白。
- 只有对话框和浮层使用 `--shadow-overlay`，且必须有 1px 墨色边框。
- 圆角只用 0 / 2px；圆形只给主题切换标记和加载环。
- 顶栏下方是 1px + 3px 间隔 + 1px 的双细线；页眉下方是 2px 墨线。
- 可点击边界至少 `--color-rule-strong`（对纸面 ≥3:1）；装饰线才用 `--color-rule`。
- 禁用态同时改底（ink-wash）、线（虚线）、字（muted），不得只降 opacity。

## 招牌结构

`TagRow` 是跨模块的字段行：

```
方形套印记号 + 11px 标签 + 点引线 + 值（编号用等宽） + 编号/日期 + 可选双线印章
一条 1px 行线，没有卡片、没有阴影
```

未来模块复用，只换编号前缀：`PL` 植株、`TK` 任务、`PT` 积分流水、`OD` 兑换单、
`NT` 通知、`FB` 反馈。

`Stamp` 是橡皮章：1px 内框 + 1px 外框、等宽小字、轻微 -1.2° 旋转；文字、线型、
颜色三重表达。`Ledger` 负责多条字段行的收尾行线。`FolioSection` 负责“01 / 标题 /
英文标签”的档案区块头。

`UiTimeline` 用 1px 竖线 + 6px 方形节点串起状态事件，最新事件在顶部；时间和标题
用等宽小字，原因作为次行说明。`UiTextArea` 与输入框同一套纸质表格样式，右下角
显示等宽字数计数。

## 图片画框

`UiFigure` 是封面与凭证的唯一容器：

| 场景     | 比例 | 结构                                     |
| -------- | ---- | ---------------------------------------- |
| 品种目录 | 1:1  | 1px 线框 + 底部编号条（`SP-001`）        |
| 品种详情 | 4:3  | 同上，宽度占详情页左栏                   |
| 后续凭证 | 1:1  | 打卡照片、任务照片、反馈图片复用同一组件 |

三种状态：加载中显示静态“载入中…”；失败显示“图片加载失败”和 44px 重试按钮；无图
显示“暂无封面”或业务文案。**不使用脉冲骨架**，画框尺寸固定，避免图片到达时位移。

图片按登录态读取：Spring 的文件接口要求 Bearer，`<img src>` 无法携带，因此由
`useFileUrl` 先取 blob 再转对象 URL。SSR 首屏输出加载中占位，客户端补图；对象 URL
在文件切换和卸载时释放。

## 暗夜模式

- `<html data-theme="light|dark">`；`nuxt.config.ts` 的内联脚本在绘制前读取
  `localStorage["student-theme"]`，否则跟随 `prefers-color-scheme`，避免闪白。
- 顶栏和认证页右上角提供 `ThemeToggle`；`useTheme` 在挂载后同步按钮状态。
- 暗夜不是纯黑：纸色 `#1B1C18`，墨色变浅，印泥红提亮到 `#D26757`；线条仍可见。
- 选择持久化；存储不可用时只在当前页面生效。两套 palette 都通过对比度测试。

## 动效

只解释状态变化：按下 90ms、颜色/边框 140ms、浮层进入 180ms / 退出 120ms；总时长
≤220ms，位移 ≤8px。禁止数字滚动、刻度生长、庆祝、抖动、骨架脉冲和持续装饰动画。
全部用 CSS transition，以继承 `prefers-reduced-motion` 降级。

## 明确不做

植物=绿色；奶油 + 衬线 + 陶土；近黑底 + 荧光绿；报纸式密排多栏；卡片堆叠；
大圆角 + 柔阴影 + 胶囊主按钮；渐变、玻璃拟态、发光描边；叶子/地球/回收三角/发芽
图标；游戏化进度环、徽章、彩带；中文 webfont、图标库、动画库。
