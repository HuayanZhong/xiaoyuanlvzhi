# 学生端视觉系统：生长手帐

本文记录 `apps/web` 的长期视觉规则。颜色、字号、间距、圆角、阴影与动效的唯一
来源是 `apps/web/app/assets/css/tokens.css`；本文解释角色和用法，不复制可执行实现。

## 主张

把学生端做成一本**被认真装饰的成长手帐**：每株植物是手帐里的主角，养护打卡是
贴在日历上的叶子贴纸，积分是收藏进册子的成果。页面像一页被认真记录的手帐，
而不是后台表格。

视觉识别来自**纸质温度 + 楷体标题 + 位置讲究的手帐装饰**；正文、按钮与数据永远
是清晰的黑体，信息永远在装饰前面。本系统同时提供日间与暗夜两套纸色，语义 token
不变，只替换 palette。

## 页面壳

- **≥ 48rem（网页）**：顶栏 64px，左侧叶形字标 + 文字导航，右侧主题切换；内容
  `max-width: 70rem`；页脚一行小字。
- **< 48rem（窄屏）**：同一顶栏压缩为 56px，只保留字标和主题切换；主导航改为
  底部固定栏，含 5 个内联叶形图标与中文标签。
- 320 / 375 / 768 / 1440 均无横向滚动，触控目标至少 44px。
- 断点只有 `48rem` 一档；组件不得发明私有断点。

## 颜色纪律

- `leaf` 作为文字色只允许用于 14px 以上粗体或带下划线的链接；正文与按钮文字用
  `ink` 或 `on-leaf`。
- `blush` 只用于失败、驳回、破坏性操作与审核意见，且必须同时有中文文字说明，
  不只靠颜色区分。
- `sticker` 只用于胶带、贴纸徽章与连续打卡，不用于普通状态点。
- 状态一律「彩点 + 中文词」：在养/进行中 = leaf，待处理 = sticker，失败 = blush，
  中性 = subtle。

## 字体

| 角色    | 规则                                                               |
| ------- | ------------------------------------------------------------------ |
| Display | 楷体栈 400，`clamp(1.75rem, 3vw, 2.25rem)` / 1.25；每屏一个        |
| 区块题  | 楷体栈 400，20px（1.25rem）/ 1.3，配右侧可选中文链接               |
| 正文    | 系统黑体 400，15px / 1.7                                           |
| 小字    | 系统黑体 400，13px / 1.6                                           |
| Label   | 系统黑体 600，12px；用于字段标签、chip、日期与编号                 |
| 读数    | 黑体 700 + `tabular-nums`，`clamp(1.5rem, 2.5vw, 2rem)`，单位 12px |

楷体栈为 `"Kaiti SC", "STKaiti", "KaiTi", "楷体", "Songti SC", "SimSun", serif`，
固定 400，`font-synthesis-weight: none`，不加载 webfont。标题在任意断点都大于读数。

## 装饰纪律

| ---------- | ------------------------------------------------- | --------------------------------------- |
| 和纸胶带   | 卡片顶部一角（普通卡左上 -3°，双卡第二张 +2°）    | 52×13px、透明度 0.8、黄/绿/珊瑚三色轮换 |
| 贴纸徽章   | 仅成就类信息（连续打卡、里程碑）                  | 胶囊 + `0 2px 0` 落影                   |
| 纸面点纹   | 仅页面底层（`body`），卡片表面永远纯色            | 22px 点阵，暗夜减弱                     |
| 手绘下划线 | 仅页面级大标题，每屏一个                          | 64×6px 胶带条，微倾                     |
| 虚线框     | 仅「可参与/可书写」容器（打卡日历、表单组、空态） | 1.5px dashed                            |
| 实线       | 对象卡、字段行、列表行                            | 1px `line`；交互边界用 `line-strong`    |

## 表面与形状

- 圆角：对象卡 16px、输入与小卡 12px、chip 与按钮胶囊、贴纸格 10px。
- 阴影只有两级：纸片感 `0 2px 0`（卡片、贴纸）与浮层 `0 8px 24px`（对话框）。
- 页面级大标题下方可有手绘下划线；区块头只有 1px 底线。
- 焦点：2px 叶绿外圈（`:focus-visible`），输入聚焦时叠加 `leaf-wash` 底。

## 中文优先与编号

- 界面主语言是中文；不出现装饰性英文微标签或卷号。
- 业务编号（`SP-004`、`ADP-…`、`CARE-…`）只作为「编号 xxx」小字出现在画框底部、
  字段行或页头 meta，不进入页面标题与正文主句。

## 暗夜模式

- `<html data-theme="light|dark">`；`nuxt.config.ts` 的内联脚本在绘制前读取
  `localStorage["student-theme"]`，否则跟随 `prefers-color-scheme`，避免闪白。
- 暗夜不是纯黑：纸色 `#26241E`，墨色变浅，叶绿提亮，贴纸与胶带降饱和。
- 选择持久化；存储不可用时只在当前页面生效。两套 palette 都通过对比度测试。

## 动效

只解释状态变化：按下 `scale(0.98)` 120ms、颜色 160ms、浮层进入 160ms / 退出
120ms、贴纸「盖上」落定 240ms（仅打卡成功）。总时长 ≤240ms，位移 ≤8px。
禁止数字滚动、进度环、庆祝、抖动、骨架脉冲与持续装饰动画；全部使用 CSS
transition，自动继承 `prefers-reduced-motion`。

## 明确不做

- 图标库、中文 webfont、动画库。
- 渐变、玻璃拟态、发光描边、背景虚化。
- 以 emoji 充当功能性图标（叶形贴纸与导航图标使用内联 SVG）。
- 大面积绿色块、营销页式视觉、满屏英文微标签。
- 档案编号卷号、点引线、方印记号、橡皮章。
